# Side by Side Editor

Neon Vision Editor can show two open documents next to each other in one window,
both editable. The feature is called **Side by Side** (in the toolbar it may be
labelled **Split**).

Dragging a tab only reorders tabs. It doesn't create a split. Use the command
below instead.

## Open two files side by side

1. Open both files so they're tabs in the **same window**.
2. Select the tab you want on the left.
3. Start Side by Side in any of these ways:
   - **View > Toggle Side by Side Editor**, or press **⌥⌘\\** (Option-Command-Backslash).
   - Click the **Side by Side** toolbar button (icon: two side-by-side rectangles).
4. If two tabs are open, the other one opens on the right straight away. If
   three or more are open, choose which document should go on the right.

Both panes are full editors. The window's commands (Find, Go to Line, and so on)
act on the pane you last clicked into.

## Close Side by Side

Choose **Toggle Side by Side Editor** again, press **⌥⌘\\**, or click the toolbar
button (it now reads **Close Side by Side Editor**). Closing the right-hand
document's tab also closes the split.

## Limits

- **Two panes only.** There are no grids or extra panes yet.
- **Same window only (Mac).** Side by Side can only use documents that are tabs
  of the current window. If the command is greyed out or offers nothing, your
  files are probably in separate windows. Choose **Window > Merge All Windows**
  to put them into one tabbed window, then try again.
- **iPad and iPhone:** use the **Side by Side** toolbar button. If it isn't
  shown, it's in the toolbar's overflow (**…**) menu.
- **Toolbar presets:** the Writing and Focus toolbar presets don't include the
  button. Use the menu command or **⌥⌘\\** there.

## Alternatives

- **Compare two documents:** **Tools > Compare Open Tabs…** shows a read-only
  diff of the current tab and another open tab. **Tools > Compare with Disk**
  compares the tab with its saved file.
- **Three or more files on the Mac:** put each document in its own window with
  **Window > Move Tab to New Window**, then arrange the windows with macOS window
  tiling (**Window > Move & Resize**, or drag a window to a screen edge).
