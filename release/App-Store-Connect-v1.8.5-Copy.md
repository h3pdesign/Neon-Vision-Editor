## Promotional Text

```text
Choose how Markdown opens, arrange your favorite mobile toolbar actions, and use more reliable editor keyboard shortcuts.
```

## What’s New — iPhone and iPad

```text
• Choose whether Markdown opens for editing or full-window reading, and switch modes from the toolbar or Command-Shift-P.
• Reorder your custom toolbar actions and show the selected number of icons.
• Use configured app shortcuts while the editor has hardware-keyboard focus, including Save As, Line Wrap, and Language Search. Built-in editing keys remain reserved.
• Remove duplicate Settings and Help keyboard bindings.
```

## What’s New — macOS

```text
• Choose whether Markdown opens for editing or full-window reading, and switch modes from the toolbar or Command-Shift-P.
• Navigate line and document boundaries with standard Command-arrow and Command-Shift-arrow keys.
• Use configurable Save As, Line Wrap, and Language Search shortcuts without the previous AI Activity Log key collision.
```

## TestFlight — What to Test

```text
Neon Vision Editor 1.8.5 focuses on Markdown opening mode, mobile toolbar order, and keyboard navigation.

Please test:
• Choose each default Markdown opening mode, open a Markdown file, switch modes with the toolbar and Command-Shift-P, then edit and save the file.
• On iPhone and iPad, customize and reorder toolbar actions, change the visible icon count, switch tabs, and reopen the app. Confirm the selected order and count remain correct.
• With a hardware keyboard attached, try the configured New Tab, Open, Save, Save As, Find, Line Wrap, and Language Search keys while the editor is focused and unfocused. Confirm Copy, Cut, Paste, Select All, Undo, Redo, and Markdown formatting still operate normally.
• On macOS, test Command-arrow and Command-Shift-arrow at line and document boundaries with and without a selection.

Please include device, OS version, keyboard model/layout, and exact reproduction steps with feedback.
```
