Desarrollado por h3p

Hilthart Pedersen — el desarrollador detrás de Neon Vision Editor.

Soy Hilthart Pedersen, conocido como h3p y en GitHub como h3pdesign. Desarrollo Neon Vision Editor como un editor independiente para plataformas Apple, entre un editor de texto básico y un IDE completo.

La principal novedad de la última versión directa de macOS es el flujo de texto plano a Markdown.

Muchos textos útiles empiezan desordenados: notas copiadas, reuniones, esquemas o archivos antiguos. Neon puede convertirlos en una propuesta Markdown revisable sin sustituir silenciosamente el original, para que la inspecciones y la aceptes de forma deliberada.

En los Mac compatibles puede usar Apple Intelligence. También puedes configurar otro proveedor de IA. La cancelación, los avisos claros y el tiempo de espera evitan que tengas que adivinar si algo sigue ejecutándose.

La función que más me alegra es la sincronización de archivos compartidos.

Con documentos en iCloud Drive, una carpeta de red u otra app, un editor puede perder cambios externos o, peor aún, sobrescribir tu trabajo.

Neon vigila las actualizaciones externas. Si cambia un archivo y la pestaña está limpia, se actualiza en el sitio conservando el cursor, la selección, el desplazamiento y la fuente de vista previa.

El editor para cada día

Empieza con el archivo que tienes delante.

Las notas se convierten en documentación, una edición HTML necesita una comprobación renderizada y un archivo compartido puede cambiar en otro dispositivo. Neon está diseñado para esos momentos sin convertir el trabajo en un proyecto IDE.

01

Markdown revisable

02

03

Archivos compartidos seguros

Actualiza documentos limpios desde iCloud Drive, carpetas de red u otra app sin sustituir el trabajo no guardado.

De notas desordenadas a una estructura útil

Haz de Markdown una propuesta, no una reescritura destructiva.

Las notas copiadas, documentos antiguos y esquemas suelen contener la estructura necesaria. Neon los convierte en un borrador Markdown revisable sin cambiar la fuente silenciosamente.

Plain text → Markdown

La decisión queda en manos del autor.

En Mac compatibles, la conversión puede usar Apple Intelligence o un proveedor configurado. El resultado es una propuesta: revisa títulos, listas, espacios y énfasis antes de decidir.

La cancelación, un estado claro de indisponibilidad y un tiempo de seguridad forman parte del flujo.

Shared-file sync

Los cambios externos deben actualizarse sin sobrescribir el trabajo.

Los documentos de iCloud Drive, carpetas de red u otras apps pueden cambiar abiertos. Neon vigila esos cambios y actualiza las pestañas limpias en el sitio.

Conserva el cursor, la selección, la vista de código y la fuente de vista previa. No sustituye los cambios sin guardar.

1

Clean tab: refresh the updated file in place.

2

Unsaved changes: keep the local versión protected.

3

Review deliberately: choose Keep Local, Reload from Disk, or Compare.

Fuente y resultado renderizado

Previsualiza Markdown, HTML y SVG donde escribes.

Markdown is not an afterthought in Neon. On Mac and iPad, a full preview can sit beside the source document; on iPhone, it opens as a focused reading view. The formatting controls remain with the editor, below document tabs, without covering the preview or a project sidebar.

HTML and SVG preview follow the same idea: edit the source, then see the output without leaving the file workflow. It is less about publishing polish and more about getting a reliable visual answer while you work.
