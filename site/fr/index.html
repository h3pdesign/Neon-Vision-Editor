Développé par h3p

Hilthart Pedersen — le développeur derrière Neon Vision Editor.

Je suis Hilthart Pedersen, connu sous le nom h3p et sur GitHub sous le nom h3pdesign. Je développe Neon Vision Editor comme un éditeur Apple indépendant, entre l’éditeur de texte basique et l’IDE complet.

La principale nouveauté de la dernière release macOS directe est le workflow de conversion du texte brut vers Markdown.

Beaucoup de textes utiles commencent dans le désordre : notes copiées, comptes rendus, plans ou anciens fichiers. Neon peut les transformer en proposition Markdown révisable, sans remplacer silencieusement l’original, afin que vous puissiez l’inspecter et l’accepter volontairement.

Sur les Mac compatibles, Apple Intelligence peut être utilisé. Vous pouvez aussi configurer un autre fournisseur IA. L’annulation, les messages clairs en cas d’indisponibilité et le délai d’expiration évitent toute incertitude.

La fonction dont je suis le plus fier reste la synchronisation des fichiers partagés.

Avec des documents dans iCloud Drive, un dossier réseau ou une autre app, un éditeur peut manquer les changements externes ou pire, écraser votre travail.

Neon surveille les mises à jour externes des documents ouverts. Si un fichier change et que l’onglet est propre, il se rafraîchit sur place en conservant le curseur, la sélection, le défilement et la source de l’aperçu.

L’éditeur du quotidien

Commencez avec le fichier sous les yeux.

Les notes deviennent de la documentation, une modification HTML demande une vérification rendue et un fichier partagé peut changer sur un autre appareil. Neon accompagne ces moments sans transformer le travail en projet IDE.

01

Markdown vérifiable

Transformez un texte non structuré en proposition Markdown tout en gardant le contrôle de l’original.

02

Aperçus complets de la source

Gardez les sources Markdown, HTML et SVG près du résultat rendu sans changer d’app.

03

Fichiers partagés sécurisés

Actualisez les documents propres depuis iCloud Drive, un dossier réseau ou une autre app sans remplacer le travail non enregistré.

Des notes brutes à une structure utile

Faites de Markdown une proposition, pas une réécriture destructive.

Des notes copiées, un ancien document ou un plan contiennent souvent déjà la structure nécessaire. Neon les transforme en brouillon Markdown révisable sans modifier silencieusement la source.

Plain text → Markdown

La décision reste entre les mains de l’auteur.

Sur les Mac compatibles, la conversion Markdown peut utiliser Apple Intelligence ou un fournisseur configuré séparément. Le résultat reste une proposition : vous vérifiez titres, listes, espaces et emphases avant de décider.

L’annulation, un état d’indisponibilité clair et un délai de sécurité font partie du workflow.

Synchronisation des fichiers partagés

Les changements externes doivent se rafraîchir sans écraser le travail.

Les documents dans iCloud Drive, des dossiers réseau ou une autre app peuvent changer ouverts. Neon surveille ces changements et actualise les onglets propres sur place.

Neon conserve le curseur, la sélection, la vue source et la source de l’aperçu. Les modifications non enregistrées ne sont pas remplacées.

1

Clean tab: refresh the updated file in place.

2

Unsaved changes: keep the local version protected.

3

Review deliberately: choose Keep Local, Reload from Disk, or Compare.

Source et résultat rendu

Prévisualisez Markdown, HTML et SVG là où vous écrivez.

Markdown est au cœur de Neon. Sur Mac et iPad, un aperçu complet peut rester à côté de la source ; sur iPhone, il s’ouvre en lecture ciblée. Les contrôles restent avec l’éditeur sans masquer l’aperçu ni la barre de projet.

Les aperçus HTML et SVG suivent la même idée : éditez la source et voyez le résultat sans quitter votre workflow.
