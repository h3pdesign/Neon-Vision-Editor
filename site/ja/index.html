h3p が開発

Neon Vision Editor の開発者、Hilthart Pedersen。

Hilthart Pedersen です。h3p として知られ、GitHub では h3pdesign として活動しています。Neon Vision Editor は、基本的なテキストエディタと完全な IDE の間を埋める、Apple 向けの独立したエディタです。

最新のmacOS直接配布版の主な追加機能は、プレーンテキストからMarkdownへのワークフローです。

役立つ文章の多くは、コピーしたメモや会議資料、下書きから始まります。Neonはそれを確認できるMarkdown提案に変えます。元の文書を黙って置き換えず、確認して意図的に採用できる構造化された出発点を提供します。

対応するMacではApple Intelligenceを利用できます。別のAIプロバイダも設定できます。キャンセル、サービス停止時の明確な通知、タイムアウトを備え、処理中かどうかを迷わせません。

個人的に最も気に入っている機能は、共有ファイルの同期です。

iCloud Driveやネットワークフォルダに文書を置いたり、別のアプリで同じファイルを開くと、外部変更を見逃したり、目の前の作業を上書きしたりしがちです。

Neonは開いている文書の外部更新を監視します。ファイルが別の場所で変更され、タブに未保存の編集がなければ、その場で更新し、カーソルや選択、スクロール位置、プレビュー元を保ちます。

v1.4.0 の新機能

大きな文書も、すべてを一度に読み込まず軽快に操作できます。

Neon の macOS エディタはディスク上のファイルを直接扱い、編集中の箇所の周囲だけに限定した仮想ビューポートを維持します。編集のたびに文書全体のバッファを再構築せず、通常の編集ワークフローを保ちます。

v1.4.3 をダウンロード

ファイルベースのエディタアーキテクチャ

文書全体を作り直さずに、編集、スクロール、選択、保存。

仮想ビューポートはスクロール位置を追い、アクティブなウィンドウを置き換える際にもカーソルと選択を保ちます。構文処理と行レイアウトは表示範囲に限定されます。

エンコーディング、改行、外部変更の処理、アトミック保存は同じファイルワークフローに残ります。100 MB 以上のファイルは、安全に確認できる明確な読み取り専用の部分プレビューとして開きます。

限定された表示範囲大きなファイルでも、操作中の編集ウィンドウだけを維持します。
見えている作業を優先行レイアウトと構文色分けは画面上の内容に集中します。
安全なファイル処理選択、エンコーディング、改行、外部変更、アトミック保存を保持します。
部分表示の保護100 MB 以上のファイルも過大なバッファを作らずに確認できます。

毎日のエディタ

目の前のファイルから始めましょう。

メモはドキュメントになり、HTML編集には表示確認が必要で、共有ファイルは別のデバイスで変わります。Neonは作業をIDEプロジェクトにせず、こうした瞬間のために設計されています。

01

確認できるMarkdown

元の文書を管理しながら、構造化されていないテキストをMarkdown提案に変換します。

02

完全なソースプレビュー

アプリを切り替えず、Markdown、HTML、SVGのソースを表示結果の近くに保ちます。

03

安全な共有ファイル

未保存の作業を置き換えず、iCloud Driveやネットワークフォルダ、別のアプリからクリーンな文書を更新します。

荒いメモから役立つ構造へ

Make Markdown a proposal, not a destructive rewrite.

コピーしたメモや古い文書、下書きにある構造を、Neonはソースを変えず確認できるMarkdown草稿にできます。

Plain text → Markdown

判断は書き手に委ねます。

対応するMacではApple Intelligenceまたは設定したプロバイダを使えます。結果は提案なので、見出しやリストを確認してから採用します。

キャンセル、明確な利用不可状態、安全なタイムアウトを備えています。

Shared-file sync

外部変更は作業を上書きせず、安全に更新されるべきです。

iCloud Driveやネットワークフォルダ、別のアプリにある文書は開いている間に変わることがあります。Neonは変更を監視し、ファイルを閉じて開き直さず、クリーンなタブをその場で更新します。

現在のカーソル、選択、ソース表示、プレビュー元を保ちます。未保存の編集がある場合、バッファを置き換えず、確認方法の選択はあなたに委ねます。

1

Clean tab: refresh the updated file in place.

2

Unsaved changes: keep the local バージョン protected.

3

Review deliberately: choose Keep Local, Reload from Disk, or Compare.

ソースと表示結果

Markdown、HTML、SVGを編集場所でプレビュー。

NeonではMarkdownを後回しにしません。MacとiPadではソースの横に完全なプレビューを表示でき、iPhoneでは集中した読書ビューを開けます。

HTMLとSVGも同じ考え方です。ファイル作業を離れずにソースを編集し、出力を確認できます。

バージョン 1.2.1 では、macOS、iPadOS、iOS で一貫したコンパクトな操作を提供する、プラットフォームに最適化されたツールバープリセットを追加しました。設定から標準、集中、開発、レビュー、完全なワークフローを選択でき、iOS は透明なステータスバー構成を維持します。

v1.2.0 の新機能

PDF とプロジェクトファイルを同じレビュー ワークフローに。

v1.2.0 では、Neon の対象がソースファイルと Markdown だけでなくなりました。PDF と PNG をレスポンシブなプロジェクト概要に含め、PDF のハイライトと関連付けた Markdown ノートで、読んでいる文書のコンテキストを保てます。

v1.4.3 をダウンロード

PDF ノートとプロジェクトプレビュー

読み、マークし、説明をソースのそばに残す。

PDF の一節をハイライトし、Markdown ノートを添付して、後から同じレビューの続きに戻れます。プロジェクトカードで Markdown と PDF を確認しやすくし、重い画像は表示中のカードにだけ読み込みます。

iPhone と iPad では、タブをダブルタップして閉じても、未保存の変更に対する既存の確認は維持されます。

PDF ハイライトマークした箇所を文書と一緒に保持します。
関連付けた Markdown ノートソース文書を失わずにコンテキストを記録できます。
PDF と PNG のカード混在するプロジェクトを一つの概要で確認できます。
必要なときだけ画像を読み込み大きなコレクションでもプレビュー中の応答性を保ちます。

Markdownカードプレビュー

プレビューの隣にプロジェクト概要を表示。

プロジェクトが1つの文書を超えても、カードパネルで周囲の文脈を保てます。グリッドまたはリストを選び、Markdownプレビューの横に配置し、カードを選択して既存のエディタタブを開きます。

カードは軽量で確認しやすく、制限された抜粋、見出し数、ローカル画像のサムネイル、明確なステータス表示で、別のエディタを開かずに目的のファイルを見つけられます。

グリッドまたはリスト作業スペースに合うレイアウトを選択。

画像サムネイル開く前に視覚的な文書を見分けられます。
